# Barcelona_80 Urban Stay — Guía digital v3.0 Final

Sitio estático listo para GitHub Pages y el dominio `barcelona80urbanstay.com`.

## Publicación sencilla
1. En GitHub, abre el repositorio `ivanvertuss/barcelona80urbanstay`.
2. Pulsa **Agregar archivo > Cargar archivos**.
3. Sube **el contenido de esta carpeta**, no la carpeta completa. `index.html` debe quedar en la raíz del repositorio.
4. Confirma con **Confirmar cambios**.
5. En **Ajustes > Páginas**, usa la rama **principal** y la carpeta **/ (raíz)**.

El archivo `CNAME` ya contiene el dominio personalizado.
