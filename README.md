# Barcelona 80 Urban Stay — v3.1 GitHub Final

Versión preparada para GitHub Pages y el dominio:

https://barcelona80urbanstay.com

## Estructura correcta

Los archivos `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `CNAME` y `.nojekyll` deben permanecer en la raíz del repositorio.

Todas las fotografías, logotipos y códigos QR deben estar dentro de la carpeta `assets`.

## Actualización sencilla desde GitHub

1. Abre la carpeta `assets` del repositorio.
2. Pulsa `Add file` > `Upload files`.
3. Sube todos los archivos que están dentro de la carpeta local `assets`.
4. Confirma los cambios.
5. Espera 1–3 minutos y recarga la web con Ctrl+F5.

No subas el archivo ZIP directamente al repositorio: primero debes descomprimirlo.
